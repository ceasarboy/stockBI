## 6. 测试脚本

测试脚本位置：`backend/tests/`

```
tests/
├── __init__.py
├── conftest.py           # pytest 配置
├── test_data_providers.py # 数据获取测试
├── test_news_api.py      # 资讯 API 测试
├── test_factor_api.py    # 因子 API 测试
└── test_factor_calculator.py # 因子计算测试
```

## 7. 测试命令

```bash
# 运行所有测试
pytest

# 运行指定测试文件
pytest tests/test_data_providers.py

# 运行指定测试用例
pytest tests/test_data_providers.py::test_akshare_connection

# 生成覆盖率报告
pytest --cov=app --cov-report=html
```
