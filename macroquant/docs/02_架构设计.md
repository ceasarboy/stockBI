# MacroQuant 架构设计文档

## 1. 系统架构概述

MacroQuant 采用分层架构设计，分为以下几层：

```
┌─────────────────────────────────────────────────────────────┐
│                      展示层 (Presentation)                   │
│  ┌─────────────────┐  ┌─────────────────┐                   │
│  │    Web UI       │  │   Mobile App    │                   │
│  │  (Jinja2+TW)    │  │   (Flutter)     │                   │
│  │  + LLM Chat     │  │                 │                   │
│  └─────────────────┘  └─────────────────┘                   │
├─────────────────────────────────────────────────────────────┤
│                      API 层 (API Layer)                      │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              FastAPI REST API                        │   │
│  │  /api/v1/webhook | /api/v1/market | /api/v1/news    │   │
│  │  /api/v1/alert | /api/v1/factor | /api/v1/data      │   │
│  │  /api/v1/chat (LLM Agent)                           │   │
│  └─────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────┤
│                    服务层 (Service Layer)                    │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌───────────┐  │
│  │NewsService│ │FactorSvc │ │AlertService│ │StockDataSvc│ │
│  └───────────┘ └───────────┘ └───────────┘ └───────────┘  │
│  ┌───────────────────────────────────────────────────────┐ │
│  │              LLM Agent Service (M12新增)               │ │
│  │  Tools封装 | ReAct循环 | 权限控制 | 记忆管理           │ │
│  └───────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│                   数据访问层 (Data Access)                   │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              SQLAlchemy ORM (Async)                  │   │
│  └─────────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────────┤
│                     数据层 (Data Layer)                      │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌───────────┐  │
│  │PostgreSQL │ │   Redis   │ │DataProviders│ │ ChromaDB  │  │
│  │           │ │  (Cache)  │ │AkShare/    │ │(向量库)   │  │
│  │           │ │           │ │Baostock    │ │  (M11新增) │  │
│  └───────────┘ └───────────┘ └───────────┘ └───────────┘  │
└─────────────────────────────────────────────────────────────┘
```

## 2. 技术栈

### 2.1 后端技术栈
| 组件 | 技术选型 | 版本 | 说明 |
|------|----------|------|------|
| Web 框架 | FastAPI | 0.104.1 | 异步、高性能 |
| ORM | SQLAlchemy | 2.0.23 | 异步支持 |
| 数据库 | PostgreSQL | 15 | 关系型数据库 |
| 缓存 | Redis | 7 | 报警缓存 |
| 向量数据库 | ChromaDB | 最新 | 文本向量化存储 (M11新增) |
| 数据验证 | Pydantic | 2.5.2 | 类型安全 |
| 数据分析 | NumPy/Pandas | 1.26.2/2.1.3 | 因子计算 |
| LLM框架 | LangChain | 最新 | Agent编排 (M12新增) |
| 本地模型 | Qwen/Llama-3 | - | 成本控制 (M12新增) |

### 2.2 数据源
| 数据源 | 用途 | 说明 |
|--------|------|------|
| AkShare | A股日线数据 | 主数据源 |
| Baostock | A股日线数据 | 备用数据源 |
| yfinance | 全球宏观数据 | 期货、外汇、大宗商品 |

### 2.3 前端技术栈
| 组件 | 技术选型 | 说明 |
|------|----------|------|
| Web UI | Jinja2 + Tailwind CSS | Bloomberg 风格暗色主题 |
| Mobile | Flutter | 跨平台移动应用 |

### 2.4 部署
| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 容器化 | Docker | 标准化部署 |
| 编排 | Docker Compose | 多容器管理 |

## 3. 数据库设计

### 3.1 ER 图

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   users     │     │   stocks    │     │ stock_daily │
├─────────────┤     ├─────────────┤     ├─────────────┤
│ id (PK)     │     │ id (PK)     │     │ id (PK)     │
│ username    │     │ symbol      │     │ stock_id(FK)│
│ email       │     │ name        │     │ trade_date  │
│ role        │     │ exchange    │     │ open        │
└─────────────┘     │ is_active   │     │ close       │
                    └─────────────┘     └─────────────┘

┌─────────────────┐     ┌─────────────────┐
│ news_categories │     │   news_items    │
├─────────────────┤     ├─────────────────┤
│ id (PK)         │◄────│ category_id(FK) │
│ name            │     │ id (PK)         │
│ description     │     │ title           │
└─────────────────┘     │ content         │
                        │ publish_time    │
                        └─────────────────┘
                              │
                              ▼
                        ┌─────────────────┐
                        │impact_predictions│
                        ├─────────────────┤
                        │ id (PK)         │
                        │ news_id (FK)    │
                        │ target_asset    │
                        │ impact_score    │
                        │ time_horizon    │
                        │ status          │
                        └─────────────────┘

┌─────────────────┐     ┌─────────────────┐
│factor_definitions│    │  factor_values  │
├─────────────────┤     ├─────────────────┤
│ id (PK)         │◄────│ factor_id (FK)  │
│ name            │     │ stock_id (FK)   │
│ family          │     │ trade_date      │
│ description     │     │ value           │
└─────────────────┘     │ rank            │
                        └─────────────────┘
```

### 3.2 表清单
| 表名 | 说明 | 记录数预估 |

| impact_predictions | 影响预判 | ~50000/年 |

| alert_rules | 报警规则 | < 1000 |
| alert_logs | 报警日志 | ~100000/年 |

## 4. API 设计

### 4.1 API 端点清单

| 模块 | 端点 | 方法 | 说明 |
|------|------|------|------|
| **Webhook** | /api/v1/webhook/tradingview | POST | TradingView 报警接收 |
| **Market** | /api/v1/market/global-snapshot | GET | 全球市场快照 |
| **News** | /api/v1/news/categories | GET/POST | 资讯分类管理 |
| | /api/v1/news/ | GET/POST | 资讯管理 |
| | /api/v1/news/{id}/predictions | GET/POST | 影响预判管理 |
| **Factor** | /api/v1/factor/definitions | GET/POST | 因子定义管理 |
| | /api/v1/factor/combinations | GET/POST | 因子组合管理 |
| | /api/v1/factor/combinations/{id}/select | POST | 因子选股 |
| **Data** | /api/v1/data/test-connection | GET | 测试数据连接 |
| | /api/v1/data/sync/stock-list | POST | 同步股票列表 |
| | /api/v1/data/sync/stock-daily/{symbol} | POST | 同步日线数据 |
| **Alert** | /api/v1/alert/rules | GET/POST | 报警规则管理 |
| | /api/v1/alert/logs | GET | 报警日志查询 |
| **LLM Agent** (M12新增) | /api/v1/chat | POST | LLM对话接口 |
| | /api/v1/chat/tools | GET | 获取可用工具列表 |
| **Indicators** | /api/v1/indicators | GET/POST | 技术指标库管理 |

## 5. 安全设计

### 5.1 认证与授权
- JWT Token 认证
- 角色权限控制（管理员/普通用户）

### 5.2 数据安全
- 密码加密存储（bcrypt）
- 敏感配置环境变量管理

## 6. 性能优化

### 6.1 数据库优化
- 索引设计（trade_date, stock_id, factor_id）
- 分区表（stock_daily, factor_values 按日期分区）

### 6.2 缓存策略
- Redis 缓存热点数据
- API 响应缓存
